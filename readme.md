# Myntra Clone Project

A responsive Myntra homepage clone built using only HTML and CSS (Flexbox).

## Features

* Responsive Header
* Navigation Menu
* Mega Menu
* Hero Banner
* Product Sections
* Categories Section
* Footer Section
* Flexbox Layout
* Responsive Design

## Technologies Used

* HTML5
* CSS3
* Flexbox
